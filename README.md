## 📖 Summary

**Anchor Yield** is a state-of-the-art FinTech platform designed for sophisticated investors seeking to maximize their capital efficiency. By leveraging institutional-grade security and advanced yield-optimization strategies, Anchor Yield provides a seamless, high-performance environment for managing digital assets, tracking portfolio growth, and executing precision investments.

The platform combines a premium, bento-grid inspired user interface with robust backend architecture to deliver a "Member-First" experience that is both powerful and intuitive.

---

## 🚀 Key Features

- **💎 Elite Dashboard**: A comprehensive, real-time overview of your portfolio performance, featuring interactive charts and bento-grid layouts.
- **🔐 Secure Identity**: Robust authentication and user profile management powered by Supabase, including secure document handling and biometric-ready flows.
- **📊 Precision Analytics**: In-depth transaction history and yield tracking using Recharts for visual data clarity.
- **📈 Investment Management**: Streamlined flows for depositing capital and deploying it into high-yield strategies.
- **✨ Premium UI/UX**: A responsive, dark-mode first design built with Tailwind CSS 4 and fluid micro-animations via Framer Motion.
- **🛠 Support Ecosystem**: Integrated customer support interface for direct communication and issue resolution.

## ⚙️ How It Works

### 1. Secure Onboarding
Users begin by creating a secure account via the **Supabase Auth** gateway. The onboarding process is designed to meet institutional standards, ensuring all member data is encrypted and managed with the highest privacy protocols.

### 2. Capital Deployment
Once authenticated, members can navigate to the **Investment Portal** to deposit assets. The platform supports seamless integration for capital injection, providing clear instructions and real-time status updates on transaction confirmations.

### 3. Yield Optimization
Deposited capital is tracked through a sophisticated data layer. The platform's frontend consumes real-time data via **React Query**, ensuring that yield calculations and portfolio balances are always up-to-date without manual refreshes.

### 4. Monitoring & Insights
The **Bento Dashboard** serves as the command center. Using **Recharts**, it visualizes complex financial data into actionable insights, allowing members to monitor their growth trajectory, analyze historical performance, and make informed rebalancing decisions.

## 🏁 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- A Supabase account and project

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/anchor-yield.git
   cd anchor-yield
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env.local` file in the root directory and add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
